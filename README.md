## 客户端设置

请选择节点后，在客户端**首页** 界面：

- 打开 **系统代理** 即可使用  

如果无法使用，请尝试：

- 开启 **虚拟网卡模式（TUN 模式）**
- 切换为 **全局模式（Global）** 客户端首页的右上角模块，2个下拉列表，小白可以无脑第一个列表选第一个，第二个列表选任何有延迟的地区

说明：

- 手机没有虚拟网卡模式  
- 电脑虚拟网卡打不开的，请点击设置里的“扳手”修复
